# 🐟 생선 바르기 게임

마우스/터치 드래그로 생선의 가시를 제거하는 캐주얼 웹 게임입니다.

## 게임 소개

생선 위에 표시된 가시를 칼로 그어 제거하는 게임입니다. 정확하고 빠르게 모든 가시를 제거하여 높은 점수를 획득하세요!

## 주요 기능

- **3가지 난이도**: 쉬움(5개), 보통(7개), 어려움(10개)
- **점수 시스템**: 가시 제거 + 정확도 + 시간 보너스
- **별점 평가**: 1~3개 별점으로 플레이 평가
- **최고 기록**: 상위 10개 기록을 로컬에 저장
- **반응형 디자인**: 데스크톱과 모바일 모두 지원

## 게임 방법

1. 난이도를 선택하고 '게임 시작' 버튼을 클릭합니다
2. 생선 위에 표시된 빨간 가시를 마우스나 터치로 드래그하여 제거합니다
3. 모든 가시를 제거하거나 시간이 종료되면 게임이 끝납니다
4. 결과 화면에서 점수와 별점을 확인할 수 있습니다

## 점수 계산

```
기본 점수 = 제거한 가시 개수 × 100
정확도 보너스 = (정확한 컷 / 전체 컷) × 500
시간 보너스 = 남은 시간(초) × 10 (시간 제한 모드만)
총점 = 기본 점수 + 정확도 보너스 + 시간 보너스
```

## 난이도별 차이

| 난이도 | 가시 개수 | 시간 제한 |
|--------|-----------|-----------|
| 쉬움   | 5개       | 무제한    |
| 보통   | 7개       | 60초      |
| 어려움 | 10개      | 45초      |

## 별점 기준

- ⭐⭐⭐ (3성): 800점 이상
- ⭐⭐☆ (2성): 500점 이상
- ⭐☆☆ (1성): 500점 미만

## 실행 방법

1. 이 저장소를 클론합니다:
   ```bash
   git clone <repository-url>
   ```

2. `index.html` 파일을 웹 브라우저에서 엽니다

3. 또는 로컬 서버를 실행합니다:
   ```bash
   # Python 3
   python -m http.server 8000

   # Node.js (http-server 필요)
   npx http-server
   ```
