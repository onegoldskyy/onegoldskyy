# 사전등록: 수정 보완 분석의 비교 전략과 판정 기준

- 작성 시점: 0단계(표 8 재현) 직후, 1~4단계 계산 전. 이 문서를 커밋한 뒤 계산을 시작한다.
- 이 목록에 없는 전략은 결과를 본 뒤 추가하지 않는다. 추가가 필요하면 "사후 탐색"으로 따로 표시한다.
- 결과를 보고 규칙, K, 집중도 식, 필터 기준을 바꾸지 않는다. 바꿔야 하면 민감도로 따로 보고한다.
- 사용자 결정(0단계 후): 원고 재무정보 규칙이 재현되지 않았으므로 **재현 정의(0단계 사전 가정)로 진행**한다. 결과요약에 이 사실을 명시한다.

## 0.6단계 구성요소(특성) 목록
- 기본 조건: 구성 전 36개월 지급 이력 + 30일 내 체결가 + 20곡 동일금액.
- 기준선: **B-a** = 기본 조건 무작위, **B-b** = 기본 조건 표본에서 재무정보 점수 상위 60곡 중 무작위 20곡.
- 필터 규칙(모든 특성 공통, 하나뿐): 기본 조건 표본 안에서 해당 특성이 **가장 나쁜 3분위(하위 1/3)를 제외**한다. 나쁜 방향은 아래 괄호. B-a에 더할 때는 남은 곡에서 무작위 20곡. B-b에 더할 때는 남은 곡에서 재무정보 점수를 다시 계산해 상위 60곡 중 무작위 20곡.
- 다양화 규칙: B-a·B-b의 후보에서 같은 반복의 K=10개 대안집합 중 선택(짝비교, 기준 = 첫 집합).

## 판정 기준 ("재무가치 있음") — 사전 고정
비교 기준은 위 표의 "비교 기준" 열을 따른다(0.6단계는 B-a, B-b 각각). 아래 조건을 **모두** 충족할 때만 "재무가치 있음", 하나라도 빠지면 "일관되지 않음".
1. 선택기간 2024에 평균 지급감소율이 기준보다 낮다.
2. 검증기간 2025와 2026(1~8월) **둘 다**에서 평균 감소율이 기준보다 낮다.
3. 세 기간 모두 지급수익률이 기준보다 0.3%p 넘게 낮지 않다(2026은 연환산 값으로 비교).
4. 평균 감소율 차이(전략 − 기준)의 **아티스트 군집 부트스트랩 95% 구간**이 두 검증기간 중 적어도 하나에서 0을 포함하지 않는다(구간 전체가 0보다 작음).

### 불확실성 계산 (사전 고정)
- 아티스트 군집 부트스트랩: 해당 기간 표본의 아티스트(singer 원문)를 복원추출해 표본을 다시 만들고, 후보군 구성·대안집합 생성·선택까지 전체를 다시 돌린다. **B = 200**, 부트스트랩 복제마다 묶음 **500개**(점추정은 3,000개). 백분위 95% 구간.
- 기간 간 반복: 세 기간의 평균 차이 부호·크기를 함께 보고한다.
- 3,000개 반복의 표준오차를 유의성으로 쓰지 않는다.
- 0.6단계 Holm 보정: 후보별 검증기간 p = min(1, 2 × min(p_2025, p_2026)), 각 기간의 부트스트랩 양측 p = 2 × min(P(Δ* ≥ 0), P(Δ* ≤ 0)). 13개 후보(F1~F8, M1~M5)에 기준선별로 Holm 보정, 유의수준 5%. 조건 1~3을 충족하고 보정 후 p < 0.05인 것만 "재무가치 있음".

## 결론 문장 규칙
- "유의하게 개선"은 군집 부트스트랩 구간이 0을 포함하지 않고 세 기간 부호가 같을 때만 쓴다. 그 외에는 "관찰되었다", "일관되지 않았다"로 쓴다.
- 모든 전략의 결과를 빠짐없이 싣는다.
