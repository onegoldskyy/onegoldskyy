# R3a. 지급감소 위험과 투자손실 위험의 개념 정의 [수정 보완 3]

| 구분 | 지급감소 위험 (현금흐름 위험) | 투자손실 위험 |
|---|---|---|
| 무엇이 줄어드는가 | 투자자가 받는 저작권료 현금흐름 | 투자원금 대비 전체 부(지급 + 가격) |
| 측정 대상 | 평가기간 지급액 vs 기준기간 지급액 | 총수익률 = (평가기간 지급 + 기말가격 − 기초가격) ÷ 기초가격 |
| 사건 정의 | 지급감소 발생: 평가기간 지급 < 기준기간 지급 | 손실 발생: 총수익률 < 0 |
| 크기 지표 | 지급감소율 = max(0, 1 − 평가기간 지급 ÷ 기준기간 지급), 평균과 p95 | 총수익률 p5(하방 꼬리), 하방편차, 손실확률 |
| 가격의 역할 | 지급 수준(분자)만 보며, 기초가격은 수익률 분모로만 쓰인다 | 가격 변화가 직접 들어간다 |
| 기준기간 선택 | 필요(원고: 선정용 직전 12개월). 기준에 따라 값이 달라진다(R3c) | 필요 없음(기초가격이 기준) |
| 주로 답하는 질문 | "작년만큼 저작권료가 들어오는가?" | "투자한 돈보다 불어났는가?" |
| 묶음(분산)의 효과 | 곡별 지급 변동의 상쇄로 감소율과 꼬리가 줄어든다 | 큰 손실(p5)은 줄지만 평균 총수익률이 음수인 해에는 손실확률이 오히려 높아질 수 있다 |

- 두 위험은 같은 집합에서도 따로 움직일 수 있다. 지급이 줄어도 가격이 올라 이익일 수 있고(감소 O·손실 X), 지급이 늘어도 가격 하락으로 손실일 수 있다(감소 X·손실 O). 실제 비중은 `tables/R3b_감소vs손실.csv`의 2×2 표에서 확인한다.
- 원고의 핵심 지표(지급감소율)는 **지급감소 위험**이다. 투자손실 위험은 보조 지표로 함께 보고한다.
- 기준기간 민감도(R3c)는 지급감소 위험에만 해당한다: ① 선정용 직전 12개월(원고), ② 평가 직전 달력연도, ③ 직전 36개월 연평균(LTY, 평가 개월 수에 맞춰 환산), ④ 월별 전년동월 대비 감소율의 평균.
