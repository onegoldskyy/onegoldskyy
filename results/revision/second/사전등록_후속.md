# 사전등록(후속 확증): 2차 탐색에서 세 기간 부호가 같았던 특성

- 작성: 2차 탐색(사후) 결과 직후, 새 자료를 보기 전. 이 문서를 커밋한 뒤 변경하지 않는다.
- 확증 자료: **2026년 연간 완성분**(2026-09 이후 수집되는 2026-09~12 지급 포함). 구성일 2026-01-01, 평가 2026-01~12. 자료가 들어오면 다음 구성일(2027-01-01, 평가 2027년)도 같은 규칙으로 추가한다.
- 대상은 아래 목록뿐이다. 다른 특성은 확증하지 않는다.

## 확증 대상 (2차 탐색에서 세 기간 Δ평균감소율 부호가 같았던 것)
| 번호 | 후보군 | 구성 | 2차 탐색 관찰 방향 | 확증 가설(사전 고정) |
|---|---|---|---|---|
| H1 | 7년 이상 / 가장 어린 3분위 제외 | F1 안정성 \|LTM/LTY−1\| 나쁜 3분위 제외 | 감소율 ↓ | 무작위 대비 평균 감소율 < 0 |
| H2 | 같음 | F2 36개월 log(1+지급) 기울기 나쁜 3분위 제외 | 감소율 ↓ | < 0 |
| H3 | 같음 | 등록 곡 수(796곡 원장) 상위 3분위만 | 감소율 ↓ | < 0 |
| H4 | 같음 | 연령 15년 이상만 | 감소율 ↓ | < 0 |
| H5 | 7년 이상 | F7 수익원 HHI 나쁜 3분위 제외 | 감소율 ↓ | < 0 |
| H6 | 7년 이상 / 가장 어린 3분위 제외 | F8 가격배수 나쁜 3분위 제외 | 감소율 ↑ (수익률 ↑) | > 0 (보조: 지급수익률 차이 > 0) |
| H7 | 같음 | 연령 15년 미만만 | 감소율 ↑ | > 0 |

보조 가설(추가 요청 B, 곡 단위 회귀):
- **B1**: 등록 곡 수(POP2) 5분위가 높을수록 log 가격배수가 높다(계수 > 0).
- **B2**: 90일 거래대금(POP3) 5분위가 높을수록 다음 해 지급감소율이 낮다(계수 < 0).

## 방법 (2차 탐색과 같게 고정)
- 표본: 0.6단계 기본 조건(구성 전 36개월 이력 + 기초가격 30일 내 체결)이다. 후보군·필터 규칙(후보군 안에서 다시 계산한 3분위), 동일금액 20곡, 묶음 3,000개, seed 20261101은 2차 탐색과 같다.
- 판정: 가설 방향과 같은 부호이고, 아티스트 군집 부트스트랩(B=500) 95% 구간이 0을 포함하지 않을 때 "확증"으로 본다. H1~H7에 Holm 보정(5%)을 하고, 두 후보군은 각각 보고한다. B1·B2는 연도 고정효과 없이 해당 구성연도 단일 회귀(아티스트 군집 표준오차, 5%)로 본다.
- 결과와 관계없이 모든 가설의 결과를 싣는다.
