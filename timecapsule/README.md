## 📖 프로젝트 소개

2025년에서 2026년으로 달려가는 붉은 말에게 당신의 새해 다짐을 실어보세요!

2026년 병오년(붉은 말의 해)을 테마로 한 인터랙티브 타임캡슐 웹사이트입니다.
사용자들이 새해 다짐을 작성하고 공유하며, 1년 후 타임캡슐처럼 다시 받아볼 수 있는 감성적인 경험을 제공합니다.

### ✨ 핵심 컨셉

- 🐴 **2026년 병오년 테마**: 붉은 말의 역동적인 애니메이션
- 📦 **타임캡슐 기능**: 1년 후 이메일로 다시 받아보기
- 📱 **모바일 우선**: 스마트폰 최적화 디자인
- 🎨 **감성적 디자인**: 밤하늘→새벽→일출 그라데이션

---

## 🎯 주요 기능

### 1. 새해 다짐 작성
- 이름 입력 (선택, 기본값: 익명)
- 다짐 텍스트 (최대 200자)
- 이메일 입력 (선택, 타임캡슐 기능)
- 실시간 글자 수 카운터

### 2. 시각적 요소
- 🐴 **붉은 말 애니메이션**
  - 화면을 가로지르는 갤럽 애니메이션
  - 다짐 보따리 표시 (개수 실시간 업데이트)
  - 불꽃 효과

- 🌌 **배경 디자인**
  - 밤하늘 → 새벽 → 일출 그라데이션
  - 반짝이는 별 애니메이션
  - 희망적인 분위기

### 3. 소셜 기능
- 📚 **다짐 갤러리**
  - 반응형 그리드 레이아웃
    - 모바일: 1열
    - 태블릿: 2열
    - 데스크톱: 3열

- 👁️ **다짐 상세 보기**
  - 카드 터치/클릭 시 모달 표시
  - 작성자명, 다짐 내용, 작성일 표시

### 4. 인터랙션
- 터치 최적화 (모바일)
- 부드러운 애니메이션
- 키보드 접근성 지원
- 반응형 피드백

## 🚀 실행 방법

### 방법 1: 직접 실행
```bash
# 파일 열기
timecapsule/index.html 파일을 웹 브라우저에서 엽니다
```

### 방법 2: 로컬 서버
```bash
# Python 3
cd timecapsule
python -m http.server 8000

# 브라우저에서 http://localhost:8000 접속
```

### 방법 3: Node.js (http-server)
```bash
cd timecapsule
npx http-server -p 8000

# 브라우저에서 http://localhost:8000 접속
```
